1. **Read [`AGENTS.md`](./AGENTS.md) first.** It contains the 10 permanently locked Founder decisions (`CONF-01`–`CONF-10`), voice routing laws, epistemic rules, and the self-correcting Learned Rules engine.
2. **Route execution through [`templates/00_MASTER_INDEX.md`](./templates/00_MASTER_INDEX.md).** All strategic and execution templates (`T-01`–`T-07`) live under `templates/` as modules inside `ABULKHAIR GROUP OS`.
3. **Respect Authority Levels (`T-07`):**
   * **Level A:** Autonomous drafting, research, auditing, and hygiene (always tagged `DRAFT` or `PROPOSED`).
   * **Level B:** Stage recommendations in `memory/decision_queue.md` for weekly Founder batch review.
   * **Level C:** Hard stop for explicit Founder sign-off (`CONF-11+`, brand/visual exceptions, publishing, financial spend, or boundary crossings).
4. **Follow the `3:1 Shipping-to-Architecture Ratio`:** Prioritize shipping real external value over endless framework expansion.
